感谢反馈——**这个功能之前确实没有，现在已经加上了**，v2.0.6 发布。

## 之前能不能关掉？

**不能，而且你可能试过的那条路（`edition` 配置）走不通**，这里说清楚免得再踩：

| 你可能的尝试 | 结果 |
| --- | --- |
| 设 `edition: "cn"` | ❌ 不生效。它只控制**扫描哪些本地安装目录**（找账号用），不控制注册哪些供应商 |
| 卸载国际版 App | ❌ 不生效。未登录/未安装时该区域会回落到插件内置的兜底模型表，与本地装没装无关 |
| 在 DSH 里隐藏 | ❌ 没有这个入口——供应商由插件注册，DSH 侧没有「停用某个供应商」的开关 |

所以你看到的 `Trae Global` 一直躺在模型选择器里，**这是真的没法关**。顺带说一句，
它列出来的那些模型（Gemini / GPT / MiniMax / Kimi）在无国际账号时**一个都调不通**，
只是兜底表把它们显示出来了——这也是 issue #8 那位用户报错的原因。

## 现在的做法：每个 tab 一个勾选

插件设置卡片里，**「国内版」「国际版」两个 tab 各带一个勾选，默认都勾选**：

- **取消勾选** = 关掉这个供应商 → 它的模型**从 DSH 模型选择器里彻底消失**
- **重新勾选** = 恢复 → 你之前选的模型、图片开关、上下文预算**原样回来**

几个你可能会关心的细节：

- **默认都勾选**，也就是说升级后你的使用方式完全不变，不想要哪边就手动取消一下。
- **关掉一侧不影响另一侧**——两边是各自独立的供应商栈，关国际版不会碰到国内版。
- **关掉后不再发任何请求**：该侧连启动时的模型目录拉取都跳过，所以「没装国际版
  每次启动报一次错」那种噪音也一并没了。
- **两个都取消也可以**，等于临时把整个插件停用；tab 会一直在，随时勾回来。

## 一个必须提醒的代价

如果你**之前有会话正在用被关闭那一侧的模型**，关闭后那个供应商的路由就被撤掉了，
该会话再用那个模型会报「找不到供应商适配器」（`NO_ADAPTER`）——这是「彻底移除」的必然结果，
不是 bug。**换回另一侧的模型即可**，或者在插件里把勾选打回来。

我们特意没有做成「静默失败」：卡片上会明确写一行提示，告诉你这个供应商已关闭、设置都还在。

欢迎升级后试一下，如果还有哪一侧你不希望出现、或者勾选行为不符合预期，直接在这里说。
