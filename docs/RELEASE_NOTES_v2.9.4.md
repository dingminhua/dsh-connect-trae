## v2.9.4（2026-10-07）

### 变更

- **关闭积分显示后，侧边栏彻底不留任何东西**（点 `×` 或取消勾选都是如此）。
  - 之前关闭后会在原位置留一个「积分」小按钮，理由是可以随时找回开关。但 2.9.3 已经把同一个复选框放进卡片**两处**（卡片顶部 + 模型区），回到开关的路本来就在配置它的地方。
  - **用户要的是清干净**：残留一个按钮仍然占着他们想腾空的位置。
- 删除不再使用的样式（`.dsm-trae-sidebar-points-off` / `-show`）与文案键（`sidebar.show` / `sidebar.showHint`）。

### 测试

- `sidebar-points` 的用例改为断言**关闭后容器里没有任何 DOM**（`container.innerHTML === ''`），而不是「还剩一个可恢复的入口」；并断言轮询也随之停止。行内 `×` 的用例同样断言完全清空。
- **变异验证被抓**：关闭时改为残留一个元素 → 2 例失败。

**完整比较**：[v2.9.3...v2.9.4](https://github.com/dingminhua/dsh-connect-trae/compare/v2.9.3...v2.9.4)
