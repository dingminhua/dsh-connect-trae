## v2.10.2（2026-10-07）

### 变更

- **侧边栏标签改为 `Trae CN 积分`**（英文 `Trae CN credits`），对齐同族插件 `dsh-connect-workbuddy` 的呈现格式：

  | | 呈现 |
  | --- | --- |
  | workbuddy | `WB CN 积分： 3,392` + 「刷新」 |
  | 本插件 | `Trae CN 积分： 3,392` + 「刷新」 |

  即「**产品缩写 + 区域 + 积分**」。上一版是 `Trae通用积分`，没有区域标记；加上 `CN` 后与 workbuddy 的两行（`WB CN 积分` / `WB AI 积分`）属于同一套视觉语言。

- 数值仍是**通用积分**（`credits.generalAvailable`），未改动。

**完整比较**：[v2.10.1...v2.10.2](https://github.com/dingminhua/dsh-connect-trae/compare/v2.10.1...v2.10.2)
