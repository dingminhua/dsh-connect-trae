## v2.10.3（2026-10-07）

> **修复：与同族插件 `dsh-connect-workbuddy` 的积分行重叠，我们的行被挤成裁切的一小条。**

### 问题

侧边栏底部同时显示两个插件的积分时，实际呈现为：

```
WB CN 积分： 3,392   刷新
WB AI 积分： 0      刷新
Tr                        ← 本插件的行只剩开头两个字母
```

**根因**：shell 把 `sidebar.footer.action` 渲染成一个**横向 flex 行**（它自己的按钮 + 每个插件的贡献都在同一行）。本插件的行容器**没有声明占满整行宽度**，于是被排到其他行旁边、挤进剩余空间。

### 修复

- 行容器加上 **`flex: 0 0 100%` 与 `min-width: 0`**，声明独占整行宽度——无论 footer 里有多少其他贡献，本行都占满一行，而不是被挤压。
- 这与 `dsh-connect-workbuddy` 的做法一致：它在自己的 Gate 注释里记录过同一问题（「fragment 让两行成为横向 flex 的兄弟节点，被并排挤在一起，用户报告不可读」），并同样以「声明宽度」解决。

### 关于测试的如实说明

这一处是**纯布局**问题。jsdom 不做布局计算，**单元测试无法覆盖**它——判断依据是真实界面截图与两处 CSS 的逐行对比。记下这一点，避免留下「测试全绿所以没问题」的错觉。
