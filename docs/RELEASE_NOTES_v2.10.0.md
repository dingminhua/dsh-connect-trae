## v2.10.0（2026-10-07）

> **新增：DSH 主界面侧边栏常驻一行「Trae通用积分」**（[#26](https://github.com/dingminhua/dsh-connect-trae/issues/26)，**实现由报告人 JiewiW 贡献**）。
>
> 看积分原先必须打开插件设置卡片、展开、找到额度区。现在侧边栏底部（工作区列表下方、设置上方）直接常驻一行「**Trae通用积分：<数值>**」与刷新按钮，**默认显示**，每 5 分钟自动更新，也可手动刷新。

> ⚠️ **npm 的 `latest` 此前仍是 2.8.0**——2.9.0～2.9.4 五个版本都未发布。本版是它们的合并发布，**从 2.8.0 升级会一次拿到全部内容**。

### 新增

- **侧边栏积分行**（`sidebar.footer.action` 槽位）：「Trae通用积分：<数值>」+ 「刷新」按钮。
  - **默认显示**；行内的 `×` 可关闭。
  - **关闭即彻底消失**：侧边栏不留任何 DOM，轮询同时停止。
  - 开启后**先立即抓取一次，完成后再启动 5 分钟周期**的定时器，不叠加；关闭或卸载即清除定时器并中止在途请求。
  - 抓取失败保留上一次数值并提示；刷新进行中忽略重复点击。
  - 显示**通用积分**（`credits.generalAvailable`，SOLO 聊天实际消耗的那个池子），与卡片数字口径一致。
  - 侧边栏收起（56px 导轨）时整行不渲染；国际版为订阅制、无可比数字，因此不显示。
- **开关共三处，写同一个字段**，永不冲突：侧边栏那一行的 `×`、卡片顶部、卡片「模型」区标题旁（「从 Trae 刷新」「一键测试启用模型」左侧）。

### 为什么不只用插件卡片里的复选框

第一版把开关**只**放在插件卡片里，结果在装了 **dshmarket** 的宿主上等于不存在：市场插件接管了插件页，而它的 UI **完全不渲染插件自带的配置卡片**（其客户端 bundle 里 `plugins.row.config` / `plugins.bundle.config` **0 处引用**）。于是积分行被挡住、开关又在打不开的页面里——**看不到功能，也找不到开关**。

现在开关同时位于**模型区**（管理模型时视线所在）与**积分行本身**，并默认显示：不再依赖任何一个可能不可达的页面。

### 本版合并的修复（2.9.1–2.9.4）

| 版本 | 修复 |
| --- | --- |
| 2.9.1 | 积分行**默认显示**，关闭入口移到行内（原为默认关闭 + 开关藏在插件卡片） |
| 2.9.2 | 标签改为「**Trae通用积分**」，避免与侧边栏里其他插件的数字混淆 |
| 2.9.3 | **补上复选框缺失的 CSS**——移植时只搬了积分行样式，漏了复选框样式，导致它一直渲染却**等同于不可见**；并在「模型」区加了同一个复选框 |
| 2.9.4 | 关闭后**彻底不显示**，不再残留「积分」小按钮 |

### 测试

- 全仓 423 → **435**：默认即显示；关闭后容器内**无任何 DOM**且轮询停止；行内 `×` 与卡片两处复选框**写同一字段、互相同步**。
- **变异验证多次全部被抓**：关闭时残留元素 → 2 例失败；去掉模型区复选框 → 2 例失败；「缺失即开启」改回「必须显式 true」→ 1 例失败；收起态不退出 → 1 例失败。
